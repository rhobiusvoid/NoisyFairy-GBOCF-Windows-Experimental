# Security

NoisyFairy runs a game you supply on your own machine and makes no network connections of its own
beyond what the game requests. It ships no game files, keys or firmware.

If you find a problem that could harm a user (for example a way for a crafted file to execute code
through the launcher or the PKG tool), please report it privately through GitHub's
"Report a vulnerability" on this repository's Security tab instead of a public issue. Include the
version, what you did and what happened. Expect a reply within a few days.

You do not need to trust the prebuilt executables: see [BUILDING.md](BUILDING.md) to build them
from source.
